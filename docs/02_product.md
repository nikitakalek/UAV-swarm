# Продукт

## 1. Что это

**SwarmCore Module** — плата, которая ставится на каждый аппарат группы и
подключается к его полётному контроллеру. Полётный контроллер продолжает делать то, что
умеет (стабилизация, навигация, аварийный возврат), а модуль решает, **куда и когда лететь
этому аппарату с учётом остальных**.

```
              Наземная станция оператора
        (ставит задачу группе, видит статус)
                       │  радиоканал
       ┌───────────────┼────────────────┐
       ▼               ▼                ▼
 ┌───────────┐   ┌───────────┐    ┌───────────┐
 │  Модуль   │◄─►│  Модуль   │◄──►│  Модуль   │   связь «борт–борт»
 │ SwarmCore │   │ SwarmCore │    │ SwarmCore │   (обмен состоянием,
 └─────┬─────┘   └─────┬─────┘    └─────┬─────┘    задачами)
       │ MAVLink       │ MAVLink        │ MAVLink   (UART, порт TELEM2)
 ┌─────▼─────┐   ┌─────▼─────┐    ┌─────▼─────┐
 │ Автопилот │   │ Автопилот │    │ Автопилот │   PX4 (в первую очередь)
 │ (PX4)     │   │ (PX4)     │    │ (PX4)     │
 └───────────┘   └───────────┘    └───────────┘
   Аппарат 1       Аппарат 2        Аппарат N
```

### Состав

| Компонент | Что это | На MVP | В серийной версии (план) |
|---|---|---|---|
| Вычислитель | компаньон-компьютер (отдельный компьютер на борту рядом с автопилотом) | Raspberry Pi 4B | вычислительный модуль на собственной плате-носителе; рассмотреть отечественный SoC |
| Связь «борт–борт» | радиомодуль mesh-сети (каждый узел ретранслирует соседей) | Wi-Fi / UDP | промышленный mesh-радиомодуль — **главная неопределённость по цене и выбору** |
| Связь с автопилотом | MAVLink по UART | MAVLink по UDP к симулятору PX4 | MAVLink по UART (TELEM2) |
| ПО модуля | наше: распределение задач, разведение аппаратов, обработка отказов | Python | Python → критичные части на C++ по результатам профилирования |
| Наземное ПО | постановка задачи группе, статус | командная строка / простая веб-страница | плагин для QGroundControl или своё приложение |

## 3. Чего мы НЕ делаем

- **Свой автопилот и свой планер.** Работаем с чужими; это наша позиция на рынке, а не
  ограничение.
- **Свою радиосистему с нуля.** Берём готовые mesh-модули.
- **Военное применение.** Только гражданские задачи.
- **«Умный рой» с ИИ ради ИИ.** Классические алгоритмы распределения задач проверены и
  предсказуемы; для гражданского заказчика предсказуемость важнее.
- **Световые шоу.** Там не нужна координация в полёте (см. [01](01_problem_and_customer.md)).

## 4. Принципы, которые отличают продукт

1. **Подключение без переделки автопилота.** Только стандартный MAVLink. Производитель не
   отдаёт нам свой код и не меняет прошивку.
2. **Безопасность — на борту и у автопилота.** Аварийные режимы (возврат домой, посадка)
   остаются за полётным контроллером; модуль не может их отключить. Любой план проверяется
   валидатором (геозоны, запас энергии, разнос аппаратов) до отправки на автопилот.
3. **Нет единой точки отказа.** Каждый модуль хранит копию состояния миссии; при потере
   наземной станции группа доделывает работу или безопасно возвращается (v1).
4. **Производитель-агностик.** Один модуль для аппаратов разных производителей в одной группе
   (долгосрочно — для эксплуатантов со смешанным парком).

## 5. Как клиент получает продукт

1. **Пилот (2027):** набор из 3 модулей + интеграция под аппарат производителя силами
   команды + лётные испытания на его площадке.
2. **Серия:** производитель ставит модуль на конвейере, получает документацию по интеграции
   и обновления ПО.
